About this app

An independent Gtuner-style workspace for Cronus Zen. GPC compilation uses the official published Zen32 compiler. The isolated connection window loads Zen Studio Live for WebHID access and the device handshake.

Titan Two GPC2 scripts are not automatically compatible with Cronus GPC. Firmware flashing and persistent slot programming are not exposed in this workspace.
